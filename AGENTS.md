# Koken

Nederlandstalige statische receptensite voor kinderen, zonder inloggen.

- Houd teksten eenvoudig en bediening toegankelijk en mobielvriendelijk.
- HTML, CSS en gewone JavaScript; geen buildstap nodig.
- Receptinhoud staat in `recipes.js`. Verzin geen hoeveelheden of porties.
- Behoud de instructie om een volwassene te vragen bij hete ovens en ovenschalen.
- Gebruik lokale afbeeldingen zonder externe trackers.
- Controleer JavaScript met `node --check app.js` en `node --check recipes.js`.
- Publicatie: GitHub Pages uit de hoofdmap van `main` in `juuul/koken`, op `https://juliaan.eu/koken/`. Geen wijzigingen bij Vimexx of aan DNS nodig.
- Bezoekers moeten de site rechtstreeks kunnen openen, zonder Cloudflare Access of ander inlogscherm.
